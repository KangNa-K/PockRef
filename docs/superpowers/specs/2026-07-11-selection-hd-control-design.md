# 选中图片 HD 控件

## 目标

让 Android 画布中选中图片的 HD 控件与 iOS 保持一致。HD 表示该图片优先使用原始分辨率显示，而不是常规按可见尺寸分级解码。

## 交互与视觉

- 控件位于选区的屏幕坐标右下角，触摸区域为 52 x 44dp。
- 当选区宽度或高度不足以容纳控件与 8dp 内边距时，控件在对应轴上居中。
- 文字为 `HD`。全部关闭时使用中性玻璃样式；全部开启时使用蓝色强调样式；多选状态不一致时使用强调样式并显示减号。
- 无选中图片、旋转手柄正在拖动，或任一选中图片为动态 GIF 时，不显示该控件。
- 点击规则与 iOS 一致：若所有选中图片均为 HD，则全部关闭；否则（包括混合态）全部开启。

## 状态与渲染

- `SceneImage` 增加 `showsOriginalResolution`，默认 `false`。
- HD 点击通过新的 `PockRefAction` 进入 ViewModel，并作为一次场景变更写入撤销历史、清空 redo、标记内容已变化。
- 图片解码请求将该持久状态视为原图优先条件：HD 开启时请求原图级别；关闭时继续使用现有可见像素尺寸加余量的分级解码策略。
- 控件采用 Compose 覆盖层，几何位置由当前选中单图或选中组的屏幕选区推导；它不参与 Canvas 的图片绘制，也不改变既有缩放角点、旋转手柄或底部选择面板。

## 保存与兼容

- 自定义 `PRFA` 场景格式升级到新版本，在每张图片的 V2 扩展字段后追加 HD 标志。
- V1、V2 文件读取时，HD 默认为关闭。
- Android 自定义格式往返保存必须保留 HD 状态。
- 桌面兼容 `.pur` 格式没有对应的私有扩展字段，不承诺跨桌面格式保存该状态；加载后默认关闭。

## 验证

1. 选择状态策略覆盖：无选中、全关、混合、全开，以及点击后的全开或全关结果。
2. 自定义场景格式往返保存保留 HD；旧版本读取默认关闭。
3. HD 操作能撤销和重做，并触发内容变更。
4. 目标单元测试和 `:app:assembleDebug` 通过。
