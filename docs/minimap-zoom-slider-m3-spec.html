Minimap 长按缩放滑块
Material 3 实现方案

把"长按 minimap / 折叠小白条 → 变形为缩放滑块 → 控制主画布 zoom"这条交互重做一遍，按 Material 3 设计语言对齐： M3 Slider / Surface / tonalElevation / MotionScheme / Ripple / HapticFeedback / TalkBack。 现有 PockRefAction.SetCanvasZoom 已在 8d9d74e 分支预留，本方案是它的**实现级落地说明书**。

01 · DECISIONS

关键决策 · 一页结论

长按触发 + M3 滑块 + 主画布同步这条链路，核心决策点 9 个。先看结论，不同意再说：

D1
复用现有 SetCanvasZoom(scale) action，不新增
该 action 的 doc 注释原话："Used by the minimap long-press zoom slider to set the zoom level directly. The zoom anchors on the canvas visual center."——就是为这个功能预留的。
D2
滑块值范围 1.0x – 5.0x，步长 0.5，离散刻度停靠
5 个整数倍（1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 3.5 / 4.0 / 4.5 / 5.0），共 9 档。Slider 内部用 steps = 8，每个整数级切换触发 HapticFeedback（haptic 也按整数级触发，符合 spec）。
D3
长按阈值默认 400ms，暴露 MinimapLongPressMs 偏好
用户建议 300-500ms 区间。取中位 400ms，并通过 AppPreferences.minimapLongPressMs 持久化（默认值 400，范围 [200, 800]），用户后续可调。
D4
形态转换用 AnimatedContent + emphasized 曲线，250ms
minimap 与 slider 共享同一个锚点（minimap 的中心点）。转换时位置锚点保持，slider 从该锚点向左/向上展开 64dp。MaterialTheme.motionScheme.emphasized 控制曲线，fastSpatial（150ms）用于内部小动效，slowEffects（250ms）用于形态转换本身。
D5
滑块本体 = M3 Slider，不自定义 thumb
使用 @OptIn(ExperimentalMaterial3Api::class) 标注 + Slider + SliderState。thumb 内部用默认圆形（colorScheme.primary 高亮当前值），track 走 colorScheme.surfaceContainerHighest（M3 spec）。
D6
背景容器 = M3 Surface + tonalElevation = 2.dp
高于现有 minimap 的 MinimapElevation = 1.dp，但低于 FAB（6dp）。Slider 在视觉层级上夹在 minimap 和 FAB 之间，正好是"工具面板"的层次。
D7
松手回弹 = tween(standard, 150ms)，边界越界 = spring(mediumBouncy)
两个动画不混用。回弹是形态转换（standard 缓动），越界回正走 spring。M3 motionScheme 里 standard 曲线对应 cubic-bezier(0.2, 0.0, 0.0, 1.0)，spring 用 Spring(dampingRatio = MediumBouncy, stiffness = Medium)。
D8
数值气泡 = TooltipBox + PlainTooltip，hover / focus / long-press 显示
气泡内容是 "2.5×" 形式（用 NumberFormat 渲染）。默认不显示，long-press / focus / 滑块值变化时短暂（1500ms）显示。
D9
loading progress = LinearProgressIndicator，但默认隐藏
spec 提到的"如适用"——PockRef 的 SetCanvasZoom 是同步动作（reducer 内立即更新 canvasScale），没有 IO。预留接口 isLoading: Boolean = false 给未来网络 / 异步 zoom 资源加载用。默认渲染 = 0 高度（不占空间）。

关键层级约束

  • 外层 MinimapWithZoomSlider 是 Box 不是 Row——minimap 和 slider 共享同一个屏幕位置（minimap 中心 = slider 中心），用 AnimatedContent 在原地切换。如果外层是 Row 会触发"minimap 在左、slider 在右"那种 OOB 设计。
  • slider 状态不进入 PockRefUiState——只有 canvasScale（最终落地的 zoom 值）通过 SetCanvasZoom 进入 state。Slider 展开/收起、tooltip 是否显示、HapticFeedback 触发都是纯本地态。
  • AnimatedContent 的 targetState 是 MinimapMode，transitionSpec 走 (fadeIn + expandIn) togetherWith (fadeOut + shrinkOut)，sizeTransform 用 tween(250, easing = EmphasizedEasing)。

为什么 canvasScale 跟 MinimapMode 分离

  1. canvasScale 是持久化数据——通过 SetCanvasZoom 进入 ViewModel，可能未来会持久化（用户期望缩放保留在重启之间，跟现有的 canvasOffset 持久化一致）。
  2. MinimapMode 是纯瞬态——按一下就回到 Idle，重启后绝不应该记得"我刚才在滑动 slider"。
  3. reducer 不该知道有 slider 这种 UI 概念——如果 MinimapMode 进 PockRefUiState，未来加一个新的 minimap 交互模式（双击 reset / 三指滑动）就要在 reducer 里加一堆 if 路径，污染领域逻辑。

06 · CODE

核心代码片段

关键 5 段代码。所有片段都基于 PockRef 现有架构：PockRefAction sealed interface、state.canvasScale、 Dimens object、combinedClickable 手势约定。文件路径标注在代码块标题里。

§6.1 新增 MinimapMode + 包装器状态 MinimapZoomSliderState.kt

KOTLIN 
// V_NOW: 长按 minimap → 缩放滑块的本地 UI 状态。
// 不进 PockRefUiState——这是纯瞬态，reducer 不该感知 UI 形态。
sealed interface MinimapMode {
    data object Idle : MinimapMode
    data object Pressing : MinimapMode        // 长按计时中（涟漪已显示）
    data object Sliding : MinimapMode       // 滑块已展开，正在拖动
    data object Releasing : MinimapMode    // 手指已松，形态回弹中
}

// 1×–5× 范围 + 9 档。slider 内部分段 = (档数 - 1) - 1 = 7？
// 注：Material 3 Slider 的 steps 参数语义是 "额外步数"，
// 所以 9 个端点 + steps=7 = 8 段，9 档。计算: steps = (maxValue - minValue) / step - 1
object MinimapZoomRange {
    const val MIN = 1.0f
    const val MAX = 5.0f
    const val STEP = 0.5f
    const val STEPS = ((MAX - MIN) / STEP).toInt() - 1   // = 7

    // 整数级（1, 2, 3, 4, 5）才触发 HapticFeedback。0.5 倍率（1.5, 2.5...）只更新值不震。
    fun isIntegerStep(value: Float): Boolean = value % 1.0f == 0f
}

// 容器状态：mode + 当前 slider 值（只用于本地 tooltip 显示，
// 真正的 canvasScale 走 ViewModel）。
class MinimapZoomSliderState {
    var mode: MinimapMode by mutableStateOf(MinimapMode.Idle)
    var localSliderValue: Float by mutableStateOf(MinimapZoomRange.MIN)
}

§6.2 Reducer 修改 PureRefViewModelTransform.kt

SetCanvasZoom 已在 8d9d74e 分支预留，但 reducer 可能还没实现 clamp。修改前先 grep -n "SetCanvasZoom" PureRefViewModelTransform.kt 确认；下面假设 reducer 是新增。
KOTLIN 
// 现有 sealed interface 已有这条（PureRefActions.kt:121）:
//   data class SetCanvasZoom(val scale: Float) : PockRefAction

internal fun setCanvasZoom(scale: Float) {
    // V_NOW: minimap long-press zoom slider 的最终落地。
    // Clamp 在 reducer 这里是 single source of truth——
    // Slider 上层 clamp 是 UX（防越界动画），reducer clamp 是契约（防 reducer 被炸）。
    val clamped = scale.coerceIn(
        com.pockref.app.ui.MinimapZoomRange.MIN,
        com.pockref.app.ui.MinimapZoomRange.MAX,
    )
    if (clamped == _uiState.value.canvasScale) return
    _uiState.update { it.copy(canvasScale = clamped) }
    // 未来：跟 SetCanvasOffsetFromMinimap 一样，dispatch 到 AppPreferences 持久化。
    // 现在不持久化——Slider 展开/收起是会话内的，下次启动回到 1.0×。
    // appPrefs.canvasScale = clamped
}

§6.3 MinimapWithZoomSlider 包装器 + AnimatedContent 形态转换 MinimapZoomSlider.kt (新文件)

KOTLIN 
// V_NOW: 包装器把 CanvasMinimap 和 MinimapZoomSliderPanel 放在同一个 Box 里，
// AnimatedContent 在原地切换。位置锚点不变——slider 中心 = minimap 中心。
@Composable
fun MinimapWithZoomSlider(
    state: PockRefUiState,
    onAction: (PockRefAction) -> Unit,
    isCollapsed: Boolean,
    onExpandMinimap: () -> Unit,
    modifier: Modifier = Modifier,
) {
    // 关键：mode 跟 localSliderValue 都在 remember 里，不进 ViewModel。
    val zoomState = remember { MinimapZoomSliderState() }
    val haptic = LocalHapticFeedback.current
    val longPressMs = AppPreferences.minimapLongPressMs   // 默认 400

    // LongPress 期间是否启用 ripple + 计时。
    val interactionSource = remember { MutableInteractionSource() }

    // M3 motionScheme: fastSpatial(150) 用于内部小动效，slowEffects(250) 用于形态转换。
    val motionScheme = MaterialTheme.motionScheme
    val emphasized = motionScheme.emphasized<Float>()    // 250ms
    val standard = motionScheme.fastEffects<Float>()     // 150ms

    Box(modifier = modifier) {
        AnimatedContent(
            targetState = zoomState.mode,
            transitionSpec = {
                val isForward = targetState !is MinimapMode.Idle
                if (isForward) {
                    (fadeIn(animationSpec = tween(250, easing = FastOutSlowInEasing)) +
                        scaleIn(initialScale = 0.85f, animationSpec = emphasized)) togetherWith
                        fadeOut(animationSpec = tween(150, easing = LinearOutSlowInEasing))
                } else {
                    fadeIn(animationSpec = tween(150, easing = LinearOutSlowInEasing)) togetherWith
                        (fadeOut(animationSpec = tween(250, easing = FastOutLinearInEasing)) +
                            scaleOut(targetScale = 0.92f, animationSpec = standard))
                } using SizeTransform(clip = false)
            },
            label = "minimap-zoom-slider-transition",
        ) { mode ->
            when (mode) {
                is MinimapMode.Idle, is MinimapMode.Pressing -> {
                    // 复用现有 CanvasMinimap（不要改它的内部实现）。
                    // 多套一个 Modifier.pointerInput 处理 long-press，
                    // 因为现有 CanvasMinimap 的 detectDragGestures 会消费 DOWN。
                    Box(
                        Modifier
                            .pointerInput(longPressMs) {
                                detectTapGestures(
                                    onLongPress = {
                                        zoomState.mode = MinimapMode.Sliding
                                        zoomState.localSliderValue = state.canvasScale
                                    },
                                    onPress = {
                                        // 涟漪反馈：onPress 立即返回 + 等 UP/CANCEL
                                        val pressScope = this
                                        val released = pressScope.tryAwaitRelease()
                                        if (!released && zoomState.mode is MinimapMode.Pressing) {
                                            // 长按期间松手 → 回到 Idle
                                            zoomState.mode = MinimapMode.Idle
                                        }
                                    },
                                )
                            }
                            .indication(interactionSource, ripple()),
                    ) {
                        CanvasMinimap(
                            state = state,
                            onAction = onAction,
                            isCollapsed = isCollapsed,
                            onExpand = onExpandMinimap,
                        )
                    }
                }
                is MinimapMode.Sliding, is MinimapMode.Releasing -> {
                    MinimapZoomSliderPanel(
                        currentValue = state.canvasScale,
                        onValueChange = { newValue ->
                            // 整数级切换 → HapticFeedback。
                            if (MinimapZoomRange.isIntegerStep(newValue) &&
                                newValue != zoomState.localSliderValue) {
                                haptic.performHapticFeedback(HapticFeedbackType.LongPress)
                            }
                            zoomState.localSliderValue = newValue
                            // debounce 60ms: 用 LaunchedEffect + collect
                            onZoomDebounced(newValue, onAction)
                        },
                        onRelease = {
                            zoomState.mode = MinimapMode.Releasing
                            // 150ms standard 缓动回弹（AnimatedContent 内部 transitionSpec 处理）
                            // 然后 → Idle
                            LaunchedEffect(Unit) {
                                delay(150)
                                zoomState.mode = MinimapMode.Idle
                            }
                        },
                    )
                }
            }
        }
    }
}

// debounce 60ms: 把高频 onValueChange 折成 16fps 的 dispatch。
private fun onZoomDebounced(
    value: Float,
    onAction: (PockRefAction) -> Unit,
) {
    // 实际用 Snapshot.withMutableSnapshot + collectLatest, 这里简写为 Channel 模型。
    // 完整实现见 MinimapZoomSlider.kt
    onAction(PockRefAction.SetCanvasZoom(value))
}

§6.4 MinimapZoomSliderPanel · M3 Surface + Slider + TooltipBox MinimapZoomSliderPanel.kt (新文件)

KOTLIN 
// V_NOW: 形态转换的目标组件。背景容器走 M3 Surface + tonalElevation=2dp，
// 介于 MinimapElevation(1) 和 FabElevation(6) 之间，符合 "工具面板" 的层次。
@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun MinimapZoomSliderPanel(
    currentValue: Float,
    onValueChange: (Float) -> Unit,
    onRelease: () -> Unit,
    modifier: Modifier = Modifier,
) {
    val tooltipState = rememberTooltipState()
    val scope = rememberCoroutineScope()
    var showProgress: Boolean by remember { mutableStateOf(false) }   // 默认隐藏

    Surface(
        modifier = modifier
            .width(240.dp)
            .height(96.dp),
        shape = RoundedCornerShape(Dimens.ChromeCornerRadius),
        color = MaterialTheme.colorScheme.surface,
        tonalElevation = 2.dp,         // 二级层级
        shadowElevation = 3.dp,        // = ToolbarElevation 一致
        border = BorderStroke(
            1.dp,
            MaterialTheme.colorScheme.outline.copy(alpha = 0.4f),
        ),
    ) {
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(horizontal = 16.dp, vertical = 12.dp),
        ) {
            // 顶部: LinearProgressIndicator (默认 0 高度，保留扩展点)
            if (showProgress) {
                LinearProgressIndicator(
                    modifier = Modifier.fillMaxWidth().height(2.dp),
                    color = MaterialTheme.colorScheme.primary,
                    trackColor = MaterialTheme.colorScheme.surfaceContainerHighest,
                )
            } else {
                Spacer(Modifier.height(0.dp))   // 占位，不影响布局
            }

            // 主体: TooltipBox + M3 Slider
            val tooltipFormatter: (Float) -> String = { v -> "${v}x" }   // "1.0x" / "2.5x" / "5.0x"
            TooltipBox(
                positionProvider = TooltipDefaults.rememberPlainTooltipPositionProvider(),
                tooltip = {
                    PlainTooltip { Text(tooltipFormatter(currentValue)) }
                },
                state = tooltipState,
            ) {
                Slider(
                    value = currentValue,
                    onValueChange = onValueChange,
                    onValueChangeFinished = {
                        scope.launch { tooltipState.show() }   // 松手再显示一次
                        onRelease()
                    },
                    valueRange = MinimapZoomRange.MIN..MinimapZoomRange.MAX,
                    steps = MinimapZoomRange.STEPS,
                    colors = SliderDefaults.colors(
                        activeTrackColor = MaterialTheme.colorScheme.primary,
                        inactiveTrackColor = MaterialTheme.colorScheme.surfaceContainerHighest,
                        activeThumbColor = MaterialTheme.colorScheme.primary,
                        inactiveThumbColor = MaterialTheme.colorScheme.primary.copy(alpha = 0.6f),
                    ),
                    modifier = Modifier
                        .fillMaxWidth()
                        .semantics {
                            contentDescription = "长按激活缩放控制，当前缩放级别 ${tooltipFormatter(currentValue)}"
                            // ↑ TalkBack 朗读
                        }
                        .onKeyEvent { event ->
                            // 键盘 ← / → 步进 0.5×；Home / End 跳端点。
                            if (event.type == KeyEventType.KeyDown) {
                                val step = when (event.key) {
                                    Key.DirectionLeft, Key.DirectionRight -> MinimapZoomRange.STEP
                                    Key.MoveHome -> -currentValue + MinimapZoomRange.MIN
                                    Key.MoveEnd -> -currentValue + MinimapZoomRange.MAX
                                    else -> return@onKeyEvent false
                                }
                                onValueChange((currentValue + step)
                                    .coerceIn(MinimapZoomRange.MIN, MinimapZoomRange.MAX))
                                true
                            } else false
                        },
                )
            }
        }
    }
}

}

回到 Idle 模式时还原原始 description，不残留"slider"的语义——TalkBack 朗读不会让用户卡在"还在 slider 上"的错觉。

键盘操作（接蓝牙键盘场景）

  • ← / → · 步进 0.5× (在 valueRange 内 clamp)
  • Home · 跳到 1.0× (MIN)
  • End · 跳到 5.0× (MAX)
  • PageUp / PageDown · 步进 1.0× (整数级)
  • Esc · 强制 mode = Idle，等同于 cancel 整个 slider

所有键位走 Modifier.onKeyEvent，不依赖 M3 Slider 的默认焦点环（避免用户期望"screenshot 看到 thumb 有 halo"时看不到）。

09 · RISK · ROLLBACK

风险与回滚

R1 · 手势冲突

症状：长按后 slider 闪一下又消失。

原因：detectTapGestures 和 detectDragGestures 抢 DOWN 事件。

缓解：长按检测放外层 wrapper 优先消费 DOWN；CanvasMinimap 的 drag 在 long-press 计时期间不响应。

R2 · 动画掉帧

症状：形态转换在 240Hz S Pen 上 jank。

原因：Slider + AnimatedContent + Surface 在主线程同步 layout。

缓解：AnimatedContent 用 contentKey + transitionSpec 的 SizeTransform；Slider 内部走 M3 优化过的 implementation path。

R3 · 持久化兼容

症状：未来把 canvasScale 持久化后，老用户的 prefs 没有这个 key。

缓解：prefs 加默认值 1.0f，AppPreferences 读不到时 fallback，跟现有 minimapZoomScale 的处理一致。

R4 · 与 minimap 折叠态冲突

症状：选中图片时 minimap 折叠成 44dp FAB icon，长按 FAB 不该触发 slider。

决策：长按 仅在 minimap 展开态（非 isCollapsed）生效；FAB icon 模式下长按保留为后续"打开 minimap"功能。

回滚方案

  1. 最小回滚：只 revert 最后一两个 commit（包装器 + slider 面板），CanvasMinimap 本身一行没改。
  2. 数据回滚：SetCanvasZoom 是 8d9d74e 预留的 action，reducer 是新增的，revert 后 canvasScale 字段保留（默认 1.0f），不影响其他 zoom 路径。
  3. 紧急回滚 tag：合并前在 a100580（merge 前的最后 commit）打 tag backup-pre-zoom-slider，真出大事直接 git reset --hard backup-pre-zoom-slider。
