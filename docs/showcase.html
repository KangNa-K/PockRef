为什么需要 PockRef

传统看图软件把图塞进网格、缩略图墙,你要的反而是「把 5 张图并排铺开 + 拖到画笔旁边 + 临时调色 + 缩放对比」。 PockRef 就做这一件事 —— 把所有参考图自由摆放在无限画布上,让画师专注于画本身。

aspect_ratio

无界画布

无限缩放与平移,画布尺寸跟得上你的构图。参考图永远摆在你最顺手的位置。

draw

S Pen 原生支持

笔身键即开框选,无需额外权限。专为 Galaxy Tab S10+ 调教,Samsung fork 也能精准识别。

join

智能吸附

边缘对边缘、角对角、旋转角度自动卡位。放图时不必逐像素对齐,一松手就到位。

bolt

四角缩放

选中的图片四角直接拖拽缩放,支持任意旋转角度下稳定锚定,转 90° 也不会飘。

timer

速写练习

选一组图,设好计时,自动切换画面。专注力的训练,跟健身一样有节奏。

cloud_off

完全离线

本地文件存储,场景可保存为 .pur 格式(与桌面端 PureRef 兼容)。无云端依赖、无账号、无追踪。

画布没有边界,没有网格,只有你和参考图。两指捏合缩放,一指拖动平移,导入图片时自动按 8f 间距 cascade 排版,无需手动对齐。

  • ✓ 一键自动排版:多张导入图按顺序自动定位
  • ✓ 双击空白处瞬间适应画布
  • ✓ 双指捏合 + 单指拖动,操作完全跟随直觉
  • ✓ 背景色 7 预设 + HSV 自定义取色

join_full 智能吸附

放图时一松手,就在该在的位置

PockRef 的吸附引擎会识别边缘对齐、角对齐、中心轴对齐三种情况, 并在 300 毫秒静止后自动卡位。同时旋转角度也有 ±5° 的吸附窗口, 接近 0°/90°/180°/270° 时自动锁死。

join_left 边缘吸附

边对边、角对角、轴对轴

拖动图片时,引擎会实时扫描其他图片的位置。一旦进入 15px 触发范围,且你 300ms 内没继续大幅度移动,吸附自动生效。

  • ✓ 边缘对齐:左/右/上/下边线贴合
  • ✓ 角对齐:左上和右上同时对齐 = 强优先级
  • ✓ 中线对齐:自动匹配目标图中心线
  • ✓ 角 > 中 > 边,智能判断最佳贴合
  • ✓ 吸附后 350ms 高亮反馈,你看得到触发了

rotate_right 旋转吸附

想转 90° 不用数角度

当你旋转图片接近 0°/45°/90°/135° 等 8 个标准角度时 (±5° 范围),保持 200ms 静止,角度自动锁定。锁定期间微调不会被吸附破坏,继续大幅度旋转才会脱离。

  • ✓ 8 个标准角度:0°/45°/90°/135°/180°/225°/270°/315°
  • ✓ ±5° 触发窗口,200ms 静止锁死
  • ✓ 锁角后继续小幅度旋转不会被破坏
  • ✓ 旋转超过 10° 自动解除锁定

transform 变换工具

四角拖拽 + 旋转锚定,所见即所得

选中的图片四周出现四个圆点。拖任意一角缩放,图片以对角为锚点放大缩小;旋转后再缩放,锚点不漂移 —— 用到了 4 个真实旋转角的几何反推算法。

  • ✓ 四角拖拽缩放,对角锚点稳定
  • ✓ 旋转 30° 后缩放,锚点跟随旋转不漂移
  • ✓ 双指捏合缩放、双指旋转,跟随直觉
  • ✓ 一键镜像翻转、左右 90° 旋转、复原
  • ✓ 非破坏性裁切,保留原图随时复原
  • ✓ 灰度转换、亮度对比度饱和度三轴调色

  • ✓ 单图时长 5s ~ 1h,休息时长 0 ~ 10min
  • ✓ 可选洗牌模式,打乱练习顺序
  • ✓ 暂停 / 继续 / 跳过休息,节奏你来定
  • ✓ 完成后显示「N / N 张,总用时」总结
  • ✓ 配置自动记忆,下次打开还是你常用的设置

import_export 导入与导出

进来容易,出去也方便

支持 4 种导入方式(相册批量、相机拍摄、剪贴板多图、文件拖拽), 2 种导出方式(单张 PNG/JPG、整张画布带背景色), 全部走系统 SAF 文件选择器,无需存储权限。

photo_library

相册批量导入

多选图片一次导入,自动按 8f 间距 cascade 排版。失败部分会提示「已导入 N 张,M 张失败」。

photo_camera

拍照直入画布

调起系统相机,拍完直接落画布。FileProvider 自动授权,无需处理 URI 兼容。

content_paste

剪贴板多图

部分相册/浏览器的多图复制,粘贴直接落画布。系统剪贴板 API 适配各种内容类型。

file_download

系统拖拽导入

支持从 Files、浏览器、相册直接拖到 PockRef 窗口。系统级 Drag & Drop,零配置。

file_save

PNG / JPG 导出

单张图片批量导出到任意文件夹,文件名冲突自动追加编号。带背景色或不带,二选一。

auto_awesome_mosaic

整画布导出

把当前画布布局整张导出,可选标准 8192px 上限或无上限原始画质。带透明 / 带背景,随意切换。

history 版本演进

从 1.0 到 1.3,持续打磨

每个版本聚焦一个核心问题。S Pen 笔身键控、模式菜单整合、智能吸附引擎、4 角缩放、SAF 保存路径优化、运行日志导出 —— 一路走来。

v1.3.0

运行日志导出 + 大图防崩

启动页 7 连击标题解锁「导出运行日志」按钮,一键打包设备/版本/最近 50 条 UI 错误/崩溃堆栈/logcat 后 500 行。同版本修复 SM-X810 上 BitmapFactory 忽略 inSampleSize 导致 9000+px 大图闪退的顽固 bug。

v1.2.4

剪贴板多图导入

系统剪贴板里有 N 张图也能全部导入画布。同步修复重命名场景后启动页标签和文件管理器不同步的 bug,以及打开失败时的 snackbar 文本过长问题。

v1.2.3

4 角缩放 + 启动页重做

四角圆点缩放(支持旋转后图片不漂移)、长按文件重命名、最近文件置顶、缩略图、自定义封面、左右滑手势。冻结模式下画布不可移动和旋转,锁更彻底。

v1.2.2

暗色模式 + 全新 Chrome 风格

Material 3 暗色 chrome 统一,minimap 折叠态 44dp FAB 风格,SelectionBottomSheet 替换旧版 SelectionFloatingToolbar。一键排版 FAB 同步上线,自动布局所有图。

v1.2.1 → v1.2.0

智能吸附 + 4 对齐

边缘吸附引擎正式上线,旋转吸附(0/45/90°...8 个标准角度)同步支持。4 对齐 + 等宽等高 + 最大最小 8 种批量对齐模式,多图整理效率倍增。

v1.0 ~ v1.1

核心交互搭建

无限画布、单/多/框选模式、.pur 文件格式(兼容桌面 PureRef)、自动保存、最近文件管理、相机导入、剪贴板导入 —— 整套参考图板基础体验成型。

groups 谁在用

school
